# Taskly

Рабочий лендинг Taskly — SaaS-сервиса для командной работы и управления
проектами. Пользователи знакомятся с возможностями продукта, выбирают тариф
и находят ответы на частые вопросы прямо на одной странице.

## Рабочий сайт

[Открыть Taskly](https://saas-landing-forni.vercel.app/)

## Возможности

- герой-блок с описанием Taskly и основными призывами к действию;
- визуальная демонстрация рабочей доски продукта;
- секция из трёх шагов: создание проекта, совместная работа и контроль результата;
- тарифы «Старт», «Команда» и «Бизнес»;
- выделение рекомендуемого тарифа;
- FAQ с раскрывающимися ответами;
- якорная навигация по ключевым разделам;
- адаптивная вёрстка для телефонов, планшетов и компьютеров;
- интерактивные состояния кнопок, тарифов и FAQ.

## Технологии

- React 19;
- Vite;
- Tailwind CSS 4;
- JavaScript (ES modules).

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite в терминале
(обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы создаются в папке `dist`.

## Проверка качества

```bash
npm run lint
```

## Структура проекта

```text
src/
├── components/
│   ├── Hero.jsx      # первый экран и демонстрация продукта
│   ├── Steps.jsx     # сценарий работы с Taskly
│   ├── Pricing.jsx   # тарифные планы
│   └── Faq.jsx       # раскрывающиеся вопросы
├── App.jsx           # композиция лендинга
├── index.css         # глобальные стили и плавная прокрутка
└── main.jsx          # точка входа React
```

## Настройка контента

Тарифы, преимущества и вопросы находятся рядом с соответствующими
компонентами в `src/components/`. Это позволяет обновлять содержание
лендинга без изменения общей архитектуры приложения.
